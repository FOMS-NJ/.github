# Franklin-Ogdensburg Mineralogical Society, Inc. (FOMS)

Franklin, New Jersey: the Fluorescent Mineral Capital of the World. Seven meetings a year, field trips to the quarries of the Franklin Marble, and *The Picking Table*, the Society's journal since the 1950s.

- **Website:** https://foms-nj.us (people, meetings, field trips, the quarries)
- **Minerals and research:** https://fomsnj.org (the Society's mineral site, maintained by W. Pazik)
- **Join:** https://foms-nj.us/membership
- **Write to us:** info@foms-nj.us

This organization holds the code for the Society's website and related tools. It was set up on 2026-10-09.
